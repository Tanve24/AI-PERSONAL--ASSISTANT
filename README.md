# AI Personal Assistant Simulation

## Introduction

AI Personal Assistant Simulation is a beginner-friendly Python project that simulates the basic functions of a personal assistant through a command-line interface.

The program allows the user to interact with a menu and perform different tasks such as checking the time and date, using a calculator, opening websites, viewing saved contacts, and calling a contact.

## Objective

The main objective of this project is to develop a simple personal assistant using Python programming concepts such as:

- Variables
- Input and output
- Conditional statements
- Loops
- Dictionaries
- Functions and modules
- Operators
- String methods
- Web browser integration

## Features

The project provides the following features:

1. Greeting the user
2. Displaying the current time
3. Displaying the current date
4. Telling a joke
5. Displaying a poem
6. Performing calculator operations
7. Opening YouTube
8. Opening Google
9. Opening weather information
10. Calling a saved contact
11. Viewing saved contacts
12. Exiting the program

## Technologies Used

- Python
- Python `datetime` module
- Python `webbrowser` module
- Command Line / Terminal

## Requirements

Python 3.x is required to run this project.

The project uses Python's built-in modules, so no additional external packages are required.
